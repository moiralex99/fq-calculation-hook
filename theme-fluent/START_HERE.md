# 🎨 COMMENCEZ ICI - Thème Fluent Design pour Directus

**Bienvenue !** Vous êtes au bon endroit pour installer un magnifique thème Fluent Design sur Directus.

---

## ⚡ Installation Ultra-Rapide (2 minutes)

### Étape 1 : Prévisualisez
Double-cliquez sur **`demo-simple.html`** pour voir le thème en action.

### Étape 2 : Copiez le CSS
1. Ouvrez **`fluent-simple.css`** dans un éditeur de texte
2. Sélectionnez tout (`Ctrl+A` ou `Cmd+A`)
3. Copiez (`Ctrl+C` ou `Cmd+C`)

### Étape 3 : Collez dans Directus
1. Connectez-vous à Directus
2. Allez dans **Settings** ⚙️
3. Cliquez sur **Project Settings**
4. Scrollez jusqu'à **Custom CSS**
5. Collez le CSS (`Ctrl+V` ou `Cmd+V`)
6. Cliquez sur **Save** 💾

### Étape 4 : Rafraîchissez
Appuyez sur `Ctrl+Shift+R` (Windows/Linux) ou `Cmd+Shift+R` (macOS)

**✅ C'est fini !** Votre Directus a maintenant le thème Fluent Design.

## ❓ Questions Fréquentes

### "Ça va casser quelque chose ?"
**Non !** Ce thème modifie uniquement les couleurs et polices. Aucun alignement ni fonctionnalité n'est touché.

### "C'est compatible avec quelle version de Directus ?"
Directus 10, 11 et supérieur. Toutes les versions avec Custom CSS.

### "Je peux le désinstaller facilement ?"
Oui, supprimez simplement le CSS dans Project Settings → Custom CSS.

### "Je peux changer les couleurs ?"
Oui ! Éditez les variables au début de `fluent-simple.css`. Exemples dans `INSTALLATION_SIMPLE.md`.

### "Et sur Mac/Linux ?"
Fonctionne parfaitement. Segoe UI est remplacé automatiquement par Inter (Google Fonts).

## 🛟 Problèmes Courants

### Les couleurs ne changent pas
1. Vérifiez que vous avez cliqué sur **Save** ✅
2. Faites un hard refresh : `Ctrl+Shift+R`
3. Videz le cache du navigateur

### Les polices ne s'affichent pas
Sur Windows, Segoe UI est natif. Sur Mac/Linux, vérifiez votre connexion internet (chargement de Google Fonts).

### Le mode sombre ne fonctionne pas
1. Dans Directus : Settings → User Preferences
2. Changez **Appearance** à "Dark"
3. Rafraîchissez la page
