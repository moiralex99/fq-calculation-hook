📋 Installation

Pour appliquer ce thème à Directus :

  1. Ouvrez le fichier fluent-simple.css
  2. Copiez tout le contenu (Ctrl+A, Ctrl+C)
  3. Dans Directus : Settings → Project Settings → Custom CSS
  4. Collez le CSS et sauvegardez
  5. Rafraîchissez votre page Directus

✅ Ce thème modifie uniquement les couleurs et polices.
✅ Les alignements et espacements natifs de Directus sont conservés.
